# Changelog

All notable changes to the 汉语拼音 (Hanyu Pinyin) Android app.
Format: [Keep a Changelog](https://keepachangelog.com).

## [1.0] — 2026-07-06 · versionCode 1

### Added
- Learn Hanyu Pinyin: 23 initials (声母), common finals (韵母), the four tones (声调) with tap-to-speak Mandarin audio.
- Pinyin input-method lesson and fast-typing tips (整句输入, 简拼, ü→v technique).
- 10 interactive typing drills: characters, words, initials, finals, sentences, shortcut drill (简拼速打), long messages, ü→v drill, 60-second speed challenge, and mixed practice — with accuracy and chars-per-minute results.
- Voice settings: choose a female (女声) or male (男声) Mandarin reading voice.
- Feedback via WhatsApp and About screen.

### Play submission
- First release: closed testing track, All Testers list, submitted for review on 2026-07-06.
